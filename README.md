# 🧠 YOlearn Backend – Django REST API for AI-Powered Learning App

## 🔗 Live URLs

- **Backend API**: [https://yolearn-1.onrender.com](https://yolearn-1.onrender.com/)
- **Frontend App**: [https://yolearn.vercel.app](https://yolearn-frontend.vercel.app/)

---
This is the **backend** for the YOlearn project – a full-stack AI-driven learning assistant that helps users analyze data using AI, save the outputs, and revisit past results. This repo contains the Django REST API used by the frontend.

> 🖥️ **Frontend repo**: [YOlearn Frontend (React + Supabase)](https://github.com/annuvrat/yolearn-frontend)

---


## ⚙️ Tech Stack

- Django 5.2
- Django REST Framework
- Gunicorn
- Supabase (PostgreSQL + Auth)
- Python-dotenv
- CORS Headers
- JWT Authentication

---

## 🚀 Features

- ✅ Analyze text & image data with AI
- ✅ JWT-secured API endpoints
- ✅ Supabase Auth support
- ✅ Deployed on [Render](https://render.com)
